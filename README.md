<h3>👩‍💻 About Me</h3>

I'm a technical professional with experience spanning **frontend development, SaaS startups, developer documentation, technical project management, and information security governance**.

My career has taken me through several sides of the software industry, from building and customizing web interfaces to managing software projects, creating developer documentation, and supporting security and compliance programs.

Some highlights of my background include:

- 🎨 **Frontend Development:** HTML, CSS, SCSS, and JavaScript-based web interfaces and branded microsites.
- 📚 **Developer Documentation:** Markdown, DocFX, and Azure DevOps, including documentation for SDKs, APIs, and integrations.
- 🚀 **SaaS & Software Delivery:** Technical project management, requirements gathering, QA, frontend prototyping, and cross-functional collaboration.
- 🔐 **Information Security & GRC:** Security governance, NIST SP 800-53, SOC 2, audit readiness, and technical documentation.
- ⚙️ **Process Improvement:** Microsoft 365, SharePoint, Forms, and Power Automate workflows.

I started my development journey through an immersive coding bootcamp in a startup incubator and went on to work in small software teams where wearing multiple hats was part of everyday life.

What connects these experiences is my interest in understanding how technology works, making complex information accessible, and helping teams turn ideas into working solutions.
